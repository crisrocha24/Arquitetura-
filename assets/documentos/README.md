# PDFs dos projetos

Coloque nesta pasta os PDFs que deseja disponibilizar publicamente. No campo `documents` do projeto correspondente, informe o título e o caminho do arquivo no `js/conteudo.js`.

```js
documents: [
  { name: 'Memorial descritivo', file: 'assets/documentos/memorial.pdf' },
],
```

Os documentos aparecem nos detalhes do projeto. Publique somente materiais autorizados e sem dados pessoais ou informações confidenciais.
