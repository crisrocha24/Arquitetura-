# Fotos dos projetos

As fotos estão organizadas por categoria:

- `residencial/`: apartamento estudantil, casa de praia, kitnets e casa de eventos.
- `corporativo/`: escritório de advocacia e sala presidencial.

Os caminhos de capa e galeria de cada projeto estão cadastrados em `js/conteudo.js`. Para adicionar um projeto, coloque suas imagens na pasta da categoria e informe os caminhos em `cover` e `gallery`.
