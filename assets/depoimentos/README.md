# Fotos dos depoimentos

Coloque aqui a foto de perfil que o cliente autorizou para publicação. Cadastre o caminho no campo `photo` do depoimento em `js/conteudo.js`.

```js
{
  quote: 'Comentário revisado e aprovado pelo cliente.',
  author: 'Nome autorizado',
  context: 'Projeto residencial',
  photo: 'assets/depoimentos/cliente.jpg'
}
```

A foto é opcional. Sem ela, o site exibe o comentário e a identificação autorizada, sem reservar um espaço vazio.
